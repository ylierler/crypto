  \section{Introduction}
  
  The definition of program completion \cite{cla78} has been extended
  to programs containing arithmetic operations and some other constructs
  used in answer set programming \cite{har17a,lif23,fan24b,fan22}.
  This note is an attempt to give a definition of completion
  that can be used   as a basis for reasoning about ASP encodings
  of the n-Queens puzzle \cite[Section~3.1]{geb11b} and similar programs.
  These programs use, explicitly or implicitly, \emph{count} aggregate
  expressions to specify, for instance, the assumption about the total
  number of queens.
  
  \section{Rules and programs}\label{sec:rules}
  
  In this section,
  the syntax of rules over a \mg\ signature %\cite[Section~2.1]{fan26b}
  is   generalized to programs with counting.
    Mini-\gringo\ signatures, terms, atoms,
  literals, comparisons, \mg\ dialects and definite/indefinite function
  symbols are defined
  as in the Dialects draft \cite[Sections~2 and~3]{fan26b}.  By~$D$ we
  denote a dialect of \mg\ that includes
  \begin{itemize}
\item the symbolic constant $\mathit{blank}$;
  \item the basic symbols $\mathit{inf}$ and $\mathit{sup}$, both
    different from symbolic constants; $\mathit{inf}$ is less than all
    numerals, and $\mathit{sup}$ is greater  than all numerals;
    \item no indefinite function symbols
  other than the interval symbol $..$ characterized by the condition
  $$\widehat{..}(m,n)=\{k: m\leq k\leq n\}.$$
\end{itemize}
A term is \emph{interval-free} if it does not
contain the interval symbol.
A term of the form $\mathit{blank}(t_1,\dots,t_k)$, where $k\geq 2$,
can be abbreviated as $(t_1,\dots,t_k)$.

An \emph{aggregate element} is a pair
$\bfx:{\bf L}$,
where $\bfx$ is a non-empty tuple of distinct variables,
and $\bf L$ is a conjunction of
literals and comparisons such that every member of~$\bfx$ occurs in~$\bf L$
\cite[Section~4]{lif22a}.  An \emph{aggregate atom} is an expression of
the form $t_1\leq \co \{E\}\leq t_2$,
where~$E$ is an aggregate element, and~$t_1$, $t_2$ are interval-free terms.
The expression $t\leq \co \{E\}$ stands for $t\leq \co \{E\}\leq
\mathit{sup}$, and $\co \{E\}\leq t$ stands for $\mathit{inf}\leq
\co \{E\}\leq t$.

A \emph{rule} is an expression of the form
\beq
H \ar B_1\land\cdots\land B_n
\eeq{rule}
($n\geq 0$), where the head~$H$ is either an atom or empty, and
each member~$B_i$ of the body is either a literal, or a comparison,
or an aggregate atom possibly preceded by \no.  (Since negations in front of
aggregate atoms are allowed, this is more general than in some of the
earlier work \cite{lif22a,fan24}.)  Rules with the empty head are called
\emph{constraints}.

A \emph{choice rule}
\beq
\{c(t_1,\dots,t_k)\}\ar B_1\land\cdots\land B_n
\eeq{choice}
where~$c$ is a symbolic constant, $t_1,\dots,t_k$ ($k\geq 0$) are terms, and
$B_1,\dots,B_n$ are as above, is shorthand for the rule
$$%\ba r
c(X_1,\dots,X_k)
\ar B_1\land\cdots\land B_n\land\no\ \no\ c(X_1,\dots,X_k)% \qquad\\
\land X_1=t_1\land\cdots\land X_k=t_k,
% \ea
$$
where $X_1,\dots,X_k$ are distinct variables that do not occur
in~(\ref{choice}).
% Rules with the empty head are called \emph{constraints}.

A variable that occurs in a rule~$R$ is \emph{local} in~$R$ if each of
its occurrences is within some aggregate element, and \emph{global} otherwise.
A rule is \emph{pure} if, for every aggregate element $\bfx:{\bf L}$ in its
body, all variables in the tuple~$\bfx$ are local \cite[Section~4]{lif22a}.
% A variable occurring in an aggregate element $\bfx:{\bf L}$ in the body of
% a pure rule is global iff it does not belong to~$\bf X$; thus the set of
% global variables in an aggregate element does not depend on the rest of
% the rule, assuming that the rule is pure.

A \emph{program} is a finite set of pure rules.

\section{Example: three n-Queens programs}\label{sec:examples}

The encodings of the n-Queens puzzle that we are interested in can be
represented in the syntax of Section~\ref{sec:rules} assuming that the
dialect~$D$ includes symbols for addition, subtraction, multiplication and
absolute value.

% \pagebreak
Program~$A$ \cite[Table~2]{geb11b}:
\begin{verbatim}

% place n queens on the chess board
n { q(1..n,1..n) } n.
% at most one queen per row/column
:- q(X,Y1), q(X,Y2), Y1 < Y2.
:- q(X1,Y), q(X2,Y), X1 < X2.
% at most one queen per diagonal
:- q(X1,Y1), q(X2,Y2), X1 < X2, |X1-X2| = |Y1-Y2|.

\end{verbatim}

In the syntax of Section~\ref{sec:rules}:
\begin{align}
& \{q(1\,..\,n,1\,..\,n)\}\ar,\label{a1}\\
& \ar \no\ n\leq  \co\{ X,Y : q(X,Y) \land X = 1\,..\,n \land Y = 1\,..\,n \}
  \leq n,
  \label{a2}\\
& \ar q(X,Y_1) \land q(X,Y_2) \land Y_1 < Y_2,\label{a3}\\
& \ar q(X_1,Y) \land q(X_2,Y) \land X_1 < X_2,\label{a4}\\
& \ar q(X_1,Y_1) \land q(X_2,Y_2) \land X_1 < X_2 \land |X_1-X_2| = |Y_1-Y_2|.
  \label{a5}
\end{align}
(We take the liberty to drop the overline in numerals $\o 1,\o 2,\dots$.)
\medskip

Program~$B$ \cite[Table~3]{geb11b}:
\begin{verbatim}

% place n queens on the chess board
{ q(1..n,1..n) }.
% exactly one queen per row/column
:- X = 1..n, not 1 { q(X,Y) } 1.
:- Y = 1..n, not 1 { q(X,Y) } 1.
% at most one queen per diagonal
:- D = 1..n*2-1, not { q(X,Y) : D = X-Y+n } 1.
:- D = 1..n*2-1, not { q(X,Y) : D = X+Y-1 } 1.

\end{verbatim}

In the syntax of Section~\ref{sec:rules}, this program
consists of rule~(\ref{a1}) and the constraints
\begin{align}
&\ar X = 1\,..\,n \land \no\ 1\leq \co\{ Y : q(X,Y) \} \leq 1,\label{b2}\\
& \ar Y = 1\,..\,n \land \no\ 1\leq \co\{ X : q(X,Y) \} \leq 1,\label{b3}\\
& \ar Z = 1\,..\,2\times n-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X-Y+n \} \leq  1,
  \label{b4}\\
& \ar Z = 1\,..\,2\times n-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X+Y-1 \} \leq  1.
  \label{b5}
\end{align}

% \pagebreak
Program~$C$ \cite[Table~4]{geb11b}:
\begin{verbatim}

% place n queens on the chess board
{ q(1..n,1..n) }.
% exactly one queen per row/column
:- X = 1..n, not 1 { q(X,Y) } 1.
:- Y = 1..n, not 1 { q(X,Y) } 1.
% pre-calculate the diagonals
d1(X,Y,X-Y+n) :- X = 1..n, Y = 1..n.
d2(X,Y,X+Y-1) :- X = 1..n, Y = 1..n.
% at most one queen per diagonal
:- D = 1..n*2-1, not { q(X,Y) : d1(X,Y,D) } 1.
:- D = 1..n*2-1, not { q(X,Y) : d2(X,Y,D) } 1.

\end{verbatim}

In the syntax of Section~\ref{sec:rules}, this program consists of
rules~(\ref{a1}),~(\ref{b2}),~(\ref{b3}) and
\begin{align}
&d1(X,Y,X-Y+n) \ar X = 1\,..\,n\land Y = 1\,..\,n,\label{c4}\\
&d2(X,Y,X+Y-1) \ar X = 1\,..\,n\land Y = 1\,..\,n,\label{c5}\\
&\ar Z = 1..2\times n-1\land not\ count \{ X,Y: q(X,Y) \land d1(X,Y,Z) \} \leq 1,\label{c6}\\
&\ar Z = 1..2\times n-1\land not\ count   \{X,Y:  q(X,Y) \land d2(X,Y,Z) \} \leq 1.\label{c7}    
\end{align}

\section{Normal and semi-normal rules} \label{sec:normal}

An \emph{equation} is a comparison of the form $t_1=t_2$.
A rule~$R$ is \emph{normal} if
\begin{itemize}
\item[(a)]
  every occurrence of a term of the form $t_1\,..\,t_2$ in~$R$
is the right-hand side of an equation, and
\item[(b)]
basic symbols other than numerals do not occur in~$R$ in the scope
of arithmetic function symbols other than the interval symbol.
\end{itemize}
(So symbolic constants, $\mathit{inf}$ and $\mathit{sup}$ are allowed
as endpoints of an interval; this is different from what the Dialects draft
requires \cite[Section~3]{fan26b}.)

A rule is called {\em semi-normal} if it satisfies condition~(a) and the
following restricted form of condition~(b):
\begin{itemize}
\item[(b$'$)]
  terms of the form $c(t_1,\dots,t_k)$, where~$c$ is a symbolic constant,
  do not occur in~$R$ in the scope
  of arithmetic function symbols other than the interval symbol.
\end{itemize}

A program is \emph{normal} if all its rules are normal,
and \emph{semi-normal} if all its rules are semi-normal.

% \pagebreak
Any semi-normal rule~$R$ can be transformed into a normal rule as
follows:
\begin{itemize}
\item make the list $c_1,\dots,c_k$ of 
  basic symbols other than numerals that have at least one occurrence in~$R$
  in the scope of an arithmetic operation other than the interval symbol;
\item substitute distinct variables $X_1,\dots,X_k$ that do not occur in~$R$
  for $c_1,\dots,c_k$;
\item append the conjunctive terms $X_1=c_1,\dots,X_k=c_k$ to the body.
\end{itemize}
The normal rule obtained by this transformation will be denoted by
$\mathit{normal}(R)$.  The notation $\mathit{normal}(\Pi)$, where~$\Pi$ is a
semi-normal program, is understood in a similar way.

As an example, consider choice rule~(\ref{a1}).  It is shorthand for
\beq
q(X_1,X_2) \ar \no\ \no\ q(X_1,X_2)
\land X_1 = 1\,..\,n \land X_2= 1\,..\,n,
\eeq{aa1}
and it is normal.  Constraints~(\ref{a2})--(\ref{a5}) are normal as well,
so that~$A$ is a normal program.  Rules (\ref{b2}), (\ref{b3})
and~(\ref{c5}) are normal.  Rules~(\ref{b4})--(\ref{c4}), (\ref{c6})
and~(\ref{c7}) are semi-normal, but not normal.  So~$B$ and~$C$ are
semi-normal programs.
The normal rules corresponding to~(\ref{b4})--(\ref{c4}), (\ref{c6})
and~(\ref{c7}) can be written as
\begin{align}
&\ar Z = 1\,..\,2\times U-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X-Y+U \} \leq  1\land U=n,
  \label{bb4}
  \\
& \ar Z = 1\,..\,2\times U-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X+Y-1 \} \leq  1 \land U=n,
\label{bb5}\\
& d1(X,Y,X-Y+U) \ar X = 1\,..\,U\land  Y = 1\,..\,U\land U=n,\label{cc4}\\
&\ar Z = 1\,..\,2\times U-1\land not\ count \{ X,Y: q(X,Y) \land d1(X,Y,Z) \} \leq 1\land U=n,\label{cc6}\\
&\ar Z = 1\,..\,2\times U-1\land not\ count   \{X,Y:  q(X,Y) \land d2(X,Y,Z) \} \leq 1\land U=n.\label{cc7}    
\end{align}
The program $\mathit{normal}(B)$ consists of
rules~(\ref{a1}),~(\ref{b2}),~(\ref{b3}),~(\ref{bb4}) and~(\ref{bb5});
$\mathit{normal}(C)$ consists of
rules~(\ref{a1}),~(\ref{b2}),~(\ref{b3}),~(\ref{c5})
and~(\ref{cc4})--(\ref{cc7}).

\section{Formulas}

In the next section we  generalize the ``natural translation''~$\nu$
\cite{lif21,lif23,fan26b,fan26} to rules with counting. The
generalized translation transforms normal rules into formulas over
the signature~$\sigma^\#$, which consists of
\begin{itemize}
\item [(i)] the sort \emph{general}, the sort \emph{set}, and the
  subsort \emph{integer} of \emph{general},
\item [(ii)] all numerals of the dialect~$D$ as object constants of the
  sort \emph{integer};
\item [(iii)] all basic symbols of~$D$ other than numerals as object
   constants of the sort \emph{general};
 \item [(iv)] expressions $c\bs k$, where~$c$ is a symbolic constant of~$D$
   and~$k$ is a positive integer, as $k$-ary function constants, with
   both arguments and value of the sort \emph{general};
\item [(v)] all definite arithmetic
  function symbols of~$D$ as function constants with both
  arguments and value of the sort \emph{integer};
\item[(vi)] the symbol $\co$ as the unary function symbol with the argument
  of the sort \emph{set} and the value of the sort \emph{general};
\item [(vii)] expressions $c/k$, where~$c$ is a symbolic constant of~$D$
  and~$k$ is a nonnegative integer, as $k$-ary predicate constants
  with arguments of the sort \emph{general};
\item [(viii)] the symbol $\leq$ as a binary predicate constant with both
  arguments of the sort \emph{general};
\item [(ix)] the symbol $\in$ as a binary predicate constant with the
  arguments of the sorts \emph{general} and \emph{set}.
\end{itemize}
(In comparison with $\sigma(D)$ defined in the Dialects draft
\cite[Section~4.1]{fan26b}, three things here
are new: the sort \emph{set}, the function symbol $\co$, and the
predicate symbol~$\in$.  On the other hand, the
symbol~$\mathit{graph}_{..}$ is not included.)

An atomic formula $(c/k)(t_1,\dots,t_k)$ can be abbreviated
as $c(t_1,\dots,t_k)$.
A term of the form $(\mathit{blank}\bs k)(t_1,\dots,t_k)$, where $k\geq 2$,
can be abbreviated as $(t_1,\dots,t_k)$.

Order relations other than~$\leq$ and chains
of inequalities are treated as abbreviations. We identify general variables
with variables occurring in rules.

In examples, the letters $I,\dots,N$ (and the same letters with subscripts)
are integer variables; $U,\dots,Z$ are general variables; and~$S$ is a set
variable.

\section{Natural translation}

About a rule~$R$ and a variable~$V$ we say that~$V$ is \emph{arithmetic
  in}~$R$ if~$V$ occurs in~$R$ at least once
\begin{itemize}
\item
  in the scope of an arithmetic function symbol, or
\item
  in the left-hand side of an equation containing the interval symbol.
\end{itemize}

We define first how~$\nu$ applies to some subexpressions of a normal rule.

\medskip\noindent \emph{1. Applying~$\nu$ to terms.}
Make the list $V_1,\dots,V_m$ of variables that are arithmetic in~$R$,
and designate~$m$ distinct integer variables as $\nu(V_1),\dots,\nu(V_m)$.
If~$t$ is a term occurring in~$R$ that does not contain the interval symbol,
then $\nu(t)$ is the term over
the signature~$\sigma^\#$ obtained from~$t$ by
\begin{itemize}
\item substituting $\nu(V_i)$ for each variable~$V_i$, and
\item replacing the symbolic constant~$c$ in each subexpression of the
  form $c(t_1,\dots,t_k)$ by~$c\bs k$.
\end{itemize}

\medskip
The transformation~$\nu$ applies to tuples of terms componentwise.

\medskip\noindent \emph{2. Applying~$\nu$ to literals:}
\begin{itemize}
\item
$\nu(p({\bf t}))$ is $(p/k)(\nu({\bf t}))$,
\item $\nu(\no\ p({\bf t}))$ is $\neg (p/k)(\nu({\bf t}))$,
\item $\nu(\no\ \no\ p({\bf t}))$ is $\neg\neg (p/k)(\nu({\bf t}))$,
\end{itemize}
where~$k$ is the length of the tuple~$\bf t$.

\medskip\noindent \emph{3. Applying~$\nu$ to comparisons: }
$\nu(t_1\prec t_2)$ is $\nu(t_1)\prec\nu(t_2)$, if~$t_2$ does not
contain the interval symbol;
$\nu(t = t_1\,..\,t_2)$ is $\nu(t_1)\leq\nu(t)\leq \nu(t_2)$.

\medskip
The transformation~$\nu$ applies to tuples of literals and comparisons
componentwise.

\medskip\noindent \emph{4. Applying~$\nu$ to aggregate atoms and to negated
aggregate atoms.}  Make the list of all occurrences of
aggregate elements in the body of~$R$ and choose, for each
aggregate element
\beq
X_1,\dots,X_k:{\bf L}
\eeq{ae}
on the list, a variable~$C$ \emph{associated} with it, so that
\begin{itemize}
\item[(i)] if {\bf L} contains no global variables
  then~$C$ is an object variable of the sort \emph{set};
\item[(ii)] if the global variables occurring in {\bf L} are $Y_1,\dots,Y_l$
  ($l>0$) then~$C$ is a function variable of arity~$l$; the sort of its value
  is \emph{set}; the sort of its $i$-th argument is \emph{integer}
  if~$Y_i$ is arithmetic in the rule, and \emph{general}
  otherwise.
\end{itemize}
The result of applying~$\nu$ to an aggregate atom
containing an aggregate element~(\ref{ae}) is the formula
obtained by replacing $\co\{X_1,\dots,X_k:{\bf L}\}$ with $\co(C)$ in case~(i),
and with $\co(C(\nu(Y_1),\dots,\nu(Y_l)))$ in case~(ii).
Applying~$\nu$ to a negated aggregate atom is performed in the same way,
with $\no$ replaced by~$\neg$.

\medskip\noindent
\emph{5.} The result of applying~$\nu$ to the empty string is~$\bot$.

\medskip\noindent
\emph{6.} The result of applying~$\nu$ to a normal rule~(\ref{rule}) is
the formula
\beq
\forall {\bf Z}(\nu(B_1)\land\cdots\land\nu(B_n) \to \nu(H)),
\eeq{nu}
where $\bf Z$ is obtained from the list of global
variables occurring in the rule
by replacing each arithmetic variable~$V$ with $\nu(V)$.

For any normal rule~$R$, the free variables of $\nu(R)$ are the variables
associated with aggregate expressions in the body of~$R$.

% The result of applying $\nu$ to a semi-normal rule~$R$ is the formula
% $\nu(\mathit{normal}(R))$.  The result of
% applying~$\nu$ to a semi-normal program~$\Pi$ is the set of sentences
% $\nu(R)%$ for all rules~$R$ of~$\Pi$.

\section{Example: translating rules of n-Queens programs}
\label{sec:examples-nu}

The result of applying~$\nu$ to rule~\eqref{aa1} is the formula
\beq
\forall I J (\neg\neg q(I,J) \land 1\leq I \leq n \land 1 \leq J \leq n \to q(I,J))
\eeq{a1f}
assuming that $I$ and $J$ are chosen as $\nu(X_1)$ and $\nu(X_2)$.

The aggregate literal in the body of constraint~(\ref{a2}) contains the
aggregate element
\beq
X,Y : q(X,Y) \land X = 1\,..\,n \land Y = 1\,..\,n,
\eeq{ae1}
which has no global variables.  The variable~$C_1$, associated
with~(\ref{ae1}), is an object variable of the sort \emph{set}, and the
result of applying~$\nu$ to rule~(\ref{a2}) is
\beq
\neg (n\leq \co(C_1)\leq n)\rar\bot.
\eeq{a2f}

Constraints~(\ref{a3}), (\ref{a4}) and~(\ref{a5}) are transformed into the
formulas
\beq
\forall XY_1Y_2(q(X,Y_1) \land q(X,Y_2) \land Y_1 < Y_2 \to \bot),
\eeq{a3f}
\beq
\forall X_1X_2Y(q(X_1,Y) \land q(X_2,Y) \land X_1 < X_2 \to \bot)
\eeq{a4f}
and
\beq
\forall I_1I_2J_1J_2
(q(I_1,J_1) \land q(I_2,J_2) \land I_1<I_2 \land |I_1-I_2|=|J_1-J_2| \to\bot).
\eeq{a5f}
Thus the translation~$\nu(A)$ of program~$A$ consists of
formulas~(\ref{a1f}) and~(\ref{a2f})--(\ref{a5f}).  The
only free variable in these formulas is~$C_1$.

The aggregate literal in the body of constraint~(\ref{b2}) contains the
aggregate element
\beq
Y : q(X,Y);
\eeq{ae2}
its global variable~$X$ is arithmetic in~(\ref{b2}).  The variable~$C_2$,
associated with~(\ref{ae2}), is a unary function variable; its value sort
is \emph{set}, and its argument sort is \emph{integer}.
The result of applying~$\nu$ to~(\ref{b2}) is
\beq
\forall I(1\leq I\leq n \land \neg (1\leq \co(C_2(I))\leq 1)\to \bot).
\eeq{b2f}

Translating rule~(\ref{b3}) is similar; in the aggregate element
\beq
X : q(X,Y)
\eeq{ae3}
the global variable~$Y$ is arithmetic, and the variable~$C_3$,
associated with~(\ref{ae3}), is of the same kind as~$C_2$.
The result of applying~$\nu$ to~(\ref{b3}) is
\beq
\forall J(1\leq J\leq n \land \neg (1\leq \co(C_3(J))\leq 1)\to \bot).
\eeq{b3f}

The aggregate literal in the body of constraint~(\ref{bb4}) contains the
aggregate element
\beq
 X,Y : q(X,Y) \land Z = X-Y+U;
\eeq{ae4}
its global variables~$Z$ and~$U$ are arithmetic in~(\ref{bb4}).
The variable~$C_4$,
associated with~(\ref{ae4}), is a binary function variable; its value sort
is \emph{set}, and each of its argument sorts is \emph{integer}.
The result of applying~$\nu$ to~(\ref{bb4}) is
\beq
\forall KN
(1\leq K\leq 2\times N-1
\land\neg(\mathit{inf}\leq\co(C_4(K,N))\leq 1)\land N=n\to\bot).
\eeq{b4f}

The aggregate literal in the body of constraint~(\ref{bb5}) contains the
aggregate element
\beq
 X,Y : q(X,Y) \land Z = X+Y-1;
\eeq{ae5}
its global variable~$Z$ is arithmetic in~(\ref{bb5}).
The variable~$C_5$,
associated with~(\ref{ae5}), is a unary function variable; its value sort
is \emph{set}, and its argument sort is \emph{integer}.

\section{Descriptions of aggregate elements}

The process of constructing the completion of a normal program~$\Pi$,
described in the next section, involves applying the translation~$\nu$
to each rule of~$\Pi$.  It uses also, for each aggregate expression
occurring in~$\Pi$, its \emph{description}, which is a
formula containing the variable~$C$ associated with that expression.
For an aggregate expression $X_1,\dots,X_k :{\bf L}$, the description
formula is constructed as follows.

\medskip\noindent\emph{Case 1:} The aggregate expression does not contain
global variables, so that $C$ is an object variable.  The description
formula is
$$\forall V(V\in C\lrar\exists\, \nu(X_1)\cdots\nu(X_k)\,
(V=(\nu(X_1),\dots,\nu(X_k))
\land \nu({\bf L}))),$$
where~$V$ is a general variable.
(If $k=1$ then $(\nu(X_1),\dots,\nu(X_k))$ is understood as~$\nu(X_1)$.)

For instance, the description of aggregate element~(\ref{ae1}) is the formula
\beq
\forall V(V\in C_1 \lrar \exists IJ(V=(I,J)\land q(I,J) \land 1\leq I\leq n
\land 1\leq J\leq n)),
\eeq{d1}
assuming that~$I$ and~$J$ are chosen as $\nu(X)$ and $\nu(Y)$.

\medskip\noindent\emph{Case 2:} The aggregate expression contains
global variables $W_1,\dots,W_l$ ($l>0$), so that $C$ is a function
variable.  The description formula is
\begin{equation}
\ba l
\forall V \nu(W_1) \cdots \nu(W_l)(V\in C(\nu(W_1),\dots,\nu(W_l))\\
\hskip 4cm\lrar
\exists\, \nu(X_1)\cdots\nu(X_k)\,(V=(\nu(X_1),\dots,\nu(X_k))
\land \nu({\bf L}))).
\ea
  \label{eq:descr2}
\end{equation}

For instance, the description of aggregate element~(\ref{ae2}) is
 \beq
 \forall V I(V\in C_2(I) \lrar \exists Y( V=Y \land q(I,Y))).
\eeq{d2}
assuming that~$I$ is chosen as $\nu(X)$.  The descriptions of aggregate
elements~(\ref{ae3}), (\ref{ae4}), (\ref{ae5}), (\ref{ae6}) and~(\ref{ae7})
are
\beq
\forall V J(V\in C_3(J) \lrar \exists X( V=X \land q(X,J))),
\eeq{d3}
\beq
\forall VKN(V\in C_4(K,N) \lrar \exists IJ(V=(I,J) \land q(I,J)
   \land K=I-J+N)),
\eeq{d4}
\beq
\forall VK(V\in C_5(K) \lrar \exists IJ(V=(I,J) \land q(I,J)
   \land K=I+J-1)),
\eeq{d5}
\beq
\forall VK(V\in C_6(K) \lrar \exists XY(V=(X,Y) \land q(X,Y) \land d1(X,Y,K))),
\eeq{d6}
\beq
\forall VK(V\in C_7(K) \lrar \exists XY(V=(X,Y) \land q(X,Y) \land d2(X,Y,K))).
\eeq{d7}

\section{Program completion}

Constructing the completion of a normal program~$\Pi$ begins with applying
the translation~$\nu$ to all rules of~$\Pi$.  The definition
of~$\nu$ gives us some freedom in selecting the variables associated with the 
aggregate expressions
\beq
\bfx_1:{\bf L_1},\dots,\bfx_m:{\bf L_m}
\eeq{lae}
occurring in rules of~$\Pi$; in the process of applying~$\nu$ we ensure
that these variables $C_1,\dots,C_m$ are pairwise distinct.  The set
of formulas $\nu(R)$ for all rules~$R$ of~$\Pi$ is denoted by $\nu(\Pi)$.
The formulas describing aggregate expressions~(\ref{lae}) are denoted by
$F_1(C_1),\dots,F_m(C_m)$.

The \emph{definition} of a predicate constant $c/k$ in~$\Pi$ is the
set of all formulas~(\ref{nu}) in~$\nu(\Pi)$ such that $\nu(H)$ contains $c/k$.
For every predicate constant~$c/k$ that occurs in $\nu(\Pi)$, its
\emph{completed definition} is the formula constructed as follows.
Choose general variables~$V_1,\dots,V_k$ that do not occur in~$\nu(\Pi)$
and rewrite each formula
$$\forall {\bf Z}(\mathit{Body} \to (c/k)(t_1,\dots,t_k))$$
in the definition of~$c/k$ as
$$\exists{\bf Z} (\mathit{Body}\land V_1=t_1\land\cdots
\land V_k=t_k) \to (c/k)(V_1,\dots,V_k).$$
After this transformation, the definition of~$c/k$ has the form
$$\{E_1 \to (c/k)(V_1,\dots,V_k),\dots,E_l \to (c/k)(V_1,\dots,V_k)\}$$
for some formulas~$E_1,\dots,E_l$.
The completed definition of~$c/k$ is the formula
$$\forall V_1\cdots V_k ((c/k)(V_1,\dots,V_k) \lrar E_1\lor\cdots\lor E_l).$$
For example, the definition of $q/2$ in program~$A$ is formula~(\ref{a1f}),
and its completed definition is
\beq
\forall V_1V_2(q(V_1,V_2)\lrar 
\exists I J(\neg\neg q(I,J) \land 1\leq I \leq n \land 1 \leq J \leq n
\land V_1=I\land V_2=J)).
\eeq{a1fcdef}

The \emph{completion} of a normal program~$\Pi$, denoted by
$\mathit{comp}(\Pi)$, is the sentence
$$\forall C_1\cdots C_m (F_1(C_1)\land\cdots\land F_m(C_m)
\to G(C_1,\dots,C_m)),$$
where $G(C_1,\dots,C_m)$ is the conjunction of
\begin{itemize}
\item   the completed definitions of all predicate constants occurring
  in~$\nu(\Pi)$, and
\item the formulas~$\nu(R)$ for all constraints~$R$ in~$\Pi$.
\end{itemize}
For a semi-normal program~$\Pi$, $\mathit{comp}(\Pi)$ is defined as
$\mathit{comp}(\mathit{normal}(\Pi))$.

For example, the completion of n-Queens program~$A$, denoted by $\mathit{comp}(A)$,  is the sentence
\beq
\forall C_1(F^A_1(C_1) \to G_A(C_1)),
\eeq{compA}
where $F^A_1(C_1)$ is~(\ref{d1}), and $G_A(C_1)$ is the conjunction of
formulas~(\ref{a1fcdef}) and (\ref{a2f})--(\ref{a5f}).
The completion of  program~$B$, denoted by $\mathit{comp}(B)$, is the sentence
\beq
\forall C_2\cdots C_5(F^B_2(C_2)\land\cdots \land F^B_5(C_5)\to
G_B(C_2,\dots,C_5)),
\eeq{compB}
where $F^B_2(C_2)$ is~(\ref{d2}), $F^B_3(C_3)$ is~(\ref{d3}), $F^B_4(C_4)$ is~(\ref{d4}),
$F^B_5(C_5)$ is~(\ref{d5}), and $G_B(C_2,\dots, C_5)$ is the conjunction of
formulas~(\ref{a1fcdef}), (\ref{b2f}), (\ref{b3f}), (\ref{b4f}),
and (\ref{b5f}).

To form the completion of program~$C$, we construct first the completed
definitions of $d1/3$ and $d2/3$ in this program:
\beq\ba l
\forall V_1V_2V_3( d1(V_1,V_2,V_3)\lrar\\

\land\; V_1=I\land V_2=J \land V_3= I-J+N));

\eeq{c4fcdef}
and
\beq
\ba l\forall V_1V_2V_3(d2(V_1,V_2,V_3)\lrar \\
\hskip 17mm
\exists I J  (1\leq I\leq n \land 1\leq J\leq n 
\land V_1=I \land V_2=J \land V_3= I+J-1)).
\ea
\eeq{c5fcdef}
The completion of program~$C$ is the sentence
\beq
\forall C_2 C_3 C_6 C_7(F^B_2(C_2)\land F^B_3(C_3)\land F^C_6(C_6)\land F^C_7(C_7)
\to  G_C(C_2, C_3, C_6, C_7)),
\eeq{compC}
where $F^C_6(C_6)$ is~(\ref{d6}),
$F^C_7(C_7)$ is~(\ref{d7}),
 and $G_C(C_2, C_3, C_6, C_7)$ is the conjunction of

\beq\ba l
\forall V_1V_2V_3( d1(V_1,V_2,V_3)\lrar\\

\section{Regular Interpretations}\label{sec:regint}
An interpretation~$\I$ of the signature~$\sigma^\#$ is \emph{regular} if
\begin{itemize}
\item the domain $|\mathit{integer}|^\I$ of the sort \emph{integer} is the
  set of numerals, and $|\mathit{set}|^\I$ is the powerset of
  $|\mathit{general}|^\I$;
\item for every numeral~$c$, the corresponding element $c^\I$
  of~$|\mathit{integer}|^\I$ is~$c$,
\item for every function constant $c\bs k$, the function $(c\bs k)^\I$ is
  one-to-one;
\item for every definite arithmetic function symbol~$f$, $f^\I=f$;
\item for every~$s$ in~$|\mathit{set}|^\I$, $\co^\I(s)$ is $\o n$ if the
  cardinality~$n$ of~$s$ is finite, and is~$\mathit{sup}$  otherwise;
\item $\leq^\I$ is a total order on $|\mathit{general}|^\I$ such that, for
  every pair~$c_1$,~$c_2$ of numerals,
  \begin{itemize}
  \item
    $(c_1)^\I\leq(c_2)^\I$ iff $c_1\leq c_2$, and
  \item
    for every~$g$ in $|\mathit{general}|^\I$, if $(c_1)^\I\leq g\leq(c_2)^\I$
    then $g\in|\mathit{integer}|^\I$;
  \end{itemize}
\item for every~$g$ in~$|\mathit{general}|^\I$ and every~$s$ in
  $|\mathit{set}|^\I$, $g\in^\I s$ iff $g\in s$.
\end{itemize}

We now list an interesting property of regular interpretations that will be used in the proof of the claim relating n-Queens programs A, B, and C.
\begin{lemma}\label{lem:eu-general}
  For a formula $F(C)$  that is the description of an aggregate expression so that~$C$ is the variable associated with that expression, every regular interpretation of $\sigma^\#$ satisfies the formulas
 \medskip
 
 (a) $\exists C\,F(C)$

 \medskip\noindent and

 \medskip
 (b)
 \begin{tabular}{l} 
  $\forall C C'(F(C)\land F(C') \to C=C')$.
\end{tabular}
\end{lemma}

\begin{proof}
Consider arbitrary aggregate expression

Let  $X_1,\dots,X_k :{\bf L}$ denote an aggregate expression that $F(C)$ is a description of.
There are two cases to consider. One when this aggregate expression does not contain global variables, and the other when it does. We focus on the second case, as the first case is similar and simpler.
Take $W_1,\dots,W_l$ to be the global variables occurring in ${\bf L}$. Variable  $C$ is a function variable and formula $F(C)$ has the form~\eqref{eq:descr2}.
In this case, formula (a) is
$$
\ba l
\exists C(
  \forall V \nu(W_1) \cdots \nu(W_l)(V\in C(\nu(W_1),\dots,\nu(W_l))\\
\hskip 4cm\lrar
\exists\, \nu(X_1)\cdots\nu(X_k)\,(V=(\nu(X_1),\dots,\nu(X_k))
\land \nu({\bf L}))) ).
\ea
$$    
It is entailed by the formula
$$
\ba l
\forall \nu(W_1) \cdots \nu(W_l) \exists S \forall V (V\in S 
\\
\hskip 4cm\lrar
\exists\, \nu(X_1)\cdots\nu(X_k)\,(V=(\nu(X_1),\dots,\nu(X_k))
\land \nu({\bf L}))),
\ea
$$
which is satisfied by all regular interpretations, because the domain of
the sort \emph{set} is the entire powerset of the domain of the sort
\emph{general}.  
Furthermore, formula~(b) is
$$\ba l
\forall C C'\Big( \Big( \big(
 \forall V \nu(W_1) \cdots \nu(W_l)(V\in C(\nu(W_1),\dots,\nu(W_l))\\
\hskip 4cm\lrar
\exists\, \nu(X_1)\cdots\nu(X_k)\,(V=(\nu(X_1),\dots,\nu(X_k))
\land \nu({\bf L}))) \big)  \wedge\\
\ \ \ \ \ \ \ \  \ \ \  \big(\forall V \nu(W_1) \cdots \nu(W_l)(V\in C'(\nu(W_1),\dots,\nu(W_l))\\
\hskip 4cm\lrar
\exists\, \nu(X_1)\cdots\nu(X_k)\,(V=(\nu(X_1),\dots,\nu(X_k))
\land \nu({\bf L})))\big)\Big)\\
\hskip 7.5cm
\to C=C'\Big).
\ea
$$
The conjunction in the antecedent implies
$$
\ba l
\forall V \nu(W_1) \cdots \nu(W_l) (V\in C(\nu(W_1),\dots,\nu(W_l))\\
\hskip 4cm\lrar
V\in C'(\nu(W_1),\dots,\nu(W_l)))
\ea
$$
and consequently
$$
\forall \nu(W_1) \cdots \nu(W_l) (C(\nu(W_1),\dots,\nu(W_l))= C'(\nu(W_1),\dots,\nu(W_l)))
$$
and hence $C=C'$.
\end{proof}


\section{Statement of Theorem~\ref{thm:ab} and its Reformulations:\\ Relating n-Queens Programs A and B}


\begin{theorem}\label{thm:ab}
The formula
\beq
\exists N(N=n\land N>0) \to (\mathit{comp}(A)\lrar\mathit{comp}(B))
\eeq{thm1}
is satisfied by all regular interpretations of $\sigma^\#$.
\end{theorem}

\subsection{First reformulation}\label{sec:reform1}

As the first step towards proving Theorem~\ref{thm:ab}, we reformulate it
as an assertion about provability in a first-order theory.


Lemma below is immediate consequence of Lemma~\ref{lem:eu-general}.
\medskip
\begin{lemma}\label{lem:eu}
  Every regular interpretation of $\sigma^\#$ satisfies the formulas
 \medskip
 
 (a) $\exists C_1\,F^A_1(C_1)$;\ \  $\exists C_i\,F^B_i(C_i)$;\ \    $\exists C_j\,F^C_j(C_j)$;
 
 \medskip\noindent and

 \medskip
 (b)
 \begin{tabular}{l} 
  $\forall C_1C'_1(F^A_1(C_1)\land F^A_1(C'_1) \to C_1=C'_1)$;\\  
 $\forall C_iC'_i(F^B_i(C_i)\land F^B_i(C'_i) \to C_i=C'_i)$;\\  
   $\forall C_jC'_j(F^C_j(C_j)\land F^C_j(C'_j) \to C_j=C'_j)$
\end{tabular}

% \beq\exists C_i\,F_i(C_i)\eeq{exists}
%  \beq\forall C_iC'_i(F_i(C_i)\land F_i(C'_i) \to C_i=C'_i)\eeq{unique}
 \medskip\noindent
  ($i=2,\dots,5$; $j=6,7$).
\end{lemma}

Consider the extension of the signature $\sigma^\#$ obtained by adding
constants $C_1^*,\dots,C_5^*$ similar to the variables $C_1,\dots,C_5$.
(So $C_1^*$ is an object constant of the sort \emph{set\/};~$C_2^*$
is a function constant with the value sort \emph{set} and the argument
sort is \emph{integer\/}; and so forth.)  By~$T_{AB}$ we denote the
first-order theory over the extended signature with the following axioms:
\begin{itemize}
\item the sentences over~$\sigma^\#$ that are satisfied by all regular
  interpretations;
\item the antecedent $\exists N(N=n\land N>0)$ of~(\ref{thm1});
  we will denote this axiom by~$\ug$;
\item the first-order sentences $F^A_1(C^*_1),F^B_2(C^*_2),\dots,F^B_5(C^*_5)$ 
  obtained from $F^A_1(C_1)$, $F^B_2(C_2)$, $\dots,$ $F^B_5(C_5)$ by
  substituting the constants $C^*_1,\dots,C^*_5$ for the variables
  $C_1,\dots,C_5$; these sentences are
\end{itemize}
\begin{align}
& \forall V(V\in C^*_1 \lrar \exists IJ(V=(I,J)\land q(I,J) \land 1\leq I\leq n
\land 1\leq J\leq n)),\label{dd1}
  \\
& \forall V I(V\in C^*_2(I) \lrar q(I,V)),\label{dd2}
  \\
&  \forall V J(V\in C^*_3(J) \lrar q(V,J)),\label{dd3}
  \\
&\forall VKN(V\in C^*_4(K,N) \lrar \exists IJ(V=(I,J) \land q(I,J)
   \land K=I-J+N)),\label{dd4}
  \\
&\forall VK(V\in C^*_5(K) \lrar \exists IJ(V=(I,J) \land q(I,J)
   \land K=I+J-1))\label{dd5}
\end{align}
(Formulas~$F^B_2(C_2^*)$ and~$F^B_3(C_3^*)$ are simplfied here.)

\medskip\noindent{\bf Theorem~\ref{thm:ab}, first reformulation.}
\emph{The sentence
  \beq
  G_A(C^*_1) \lrar G_B(C^*_2,\dots,C^*_5)
  \eeq{reform1}
is provable in the theory $T_{AB}$.}

\medskip
This reformulation is proved below, and then the
original version of Theorem~\ref{thm:ab}
will follow.  Indeed, consider any regular interpretation~$\I$
of the signature~$\sigma^\#$ that satisfies the antecedent~$\ug$
of~(\ref{thm1}); we need to verify that~$\I$ satisfies the consequent
of~(\ref{thm1}).
Consider an extension of~$\I$ to the signature of~$T_{AB}$ that
satisifes $F^A_1(C_1^*),F^B_2(C_2^*),\dots,F_5^B(C_5^*)$; such an extension exists by
Lemma~\ref{lem:eu}(a). We take the liberty to denote that
extension by the same symbol~$\I$. Since~$\I$ satisfies all axioms of
the theory~$T_{AB}$,
$\I$ satisfies its theorem~(\ref{reform1}), which is equivalent to
$$\forall C_1( C_1=C_1^*\to G_A(C_1)) \lrar
\forall C_2\cdots C_5(C_2=C_2^* \land\cdots \land C_5=C_5^* \to
G_B(C_2,\dots,C_5)).$$
From Lemma~\ref{lem:eu}(b) we conclude
that~$\I$ satisfies also the formulas
$$
\ba l
\forall C_1(F^A_1(C_1) \lrar C_1=C^*_1),\\
\forall C_i(F^B_i(C_i) \lrar C_i=C^*_i) \qquad (i=2,\dots,5),\\
\ea
$$
It follows that~$\I$ satisfies the equivalence
$$\forall C_1(F^A_1(C_1) \to G_A(C_1)) \lrar
\forall C_2\cdots C_5(F^B_2(C_2)\land\cdots \land F^B_5(C_5)\to
G_B(C_2,\dots,C_5)),$$
which is identical to the consequent $\mathit{comp}(A)\lrar\mathit{comp}(B)$
of~(\ref{thm1}).

\subsection{Second reformulation}\label{sec:reformThm1}

In this section we simplify several subformulas of equivalence~(\ref{reform1}).
Recall that $G_A(C_1)$ is the conjunction of
formulas~(\ref{a1fcdef}) and (\ref{a2f})--(\ref{a5f}), and
$G_B(C_2,\dots, C_5)$ is the conjunction of
formulas~(\ref{a1fcdef}), (\ref{b2f}), (\ref{b3f}), (\ref{b4f}),
and (\ref{b5f}).

\medskip\noindent\emph{1.}
Formula~(\ref{a1fcdef}) is logically equivalent to the formula
$$
\forall X Y (q(X,Y) \to
1 \leq X \leq n \land 1 \leq Y \leq n \land \exists I(I=X)
\land \exists J(J=Y) \land \exists N(N=n)),
$$
which will be denoted by~$\dOne$.  It belongs to both
conjunctions, and by~$T'_{AB}$ we denote the theory obtained by adding~$\dOne$
to~$T_{AB}$ as an axiom.

\medskip\noindent\emph{2.}
The result of substituting $C_1^*$ for $C_1$ in~(\ref{a2f}) is equivalent
in~$T_{AB}$ to
the conjunction of the formulas
$\co(C^*_1)\geq n$ and $\co(C^*_1)\leq n$.  These formulas will be
denoted by~$\aTwofgeq$ and~$\aTwofleq$.

\medskip\noindent\emph{3.}
Formula~(\ref{a3f}) is equivalent in~$T_{AB}$ to the formula
$$\forall XY_1Y_2(q(X,Y_1) \land q(X,Y_2) \to Y_1 \geq Y_2),$$
which implies
$$\forall XY_1Y_2(q(X,Y_1) \land q(X,Y_2) \to Y_2 \geq Y_1)$$
(substitute~$Y_2$,~$Y_1$ for~$Y_1$,~$Y_2$). It follows that~(\ref{a3f}) is
equivalent to
$$
\forall XY_1Y_2(q(X,Y_1) \land q(X,Y_2) \to Y_1 = Y_2).
$$
This formula will be denoted by $\aThreefs$.

\medskip\noindent\emph{4.}
A similar calculation shows that~(\ref{a4f})
is equivalent to the formula
$$\forall X_1X_2Y(q(X_1,Y) \land q(X_2,Y) \to X_1 = X_2),$$
denoted by $\aFourfs$.

\medskip\noindent\emph{5.}
Formula~(\ref{a5f})
is equivalent in~$T_{AB}$ to the formula
$$\forall I_1I_2J_1J_2
(q(I_1,J_1) \land q(I_2,J_2) \land |I_1-I_2|=|J_1-J_2| \to I_1 \geq I_2),$$
which implies
$$\forall I_1I_2J_1J_2
(q(I_1,J_1) \land q(I_2,J_2) \land |I_1-I_2|=|J_1-J_2| \to I_2 \geq I_1)
$$
(substitute~$I_2,\,I_1,\,J_2,\,J_1$ for $I_1,\,I_2,\,J_1,\,J_2$).
Hence~(\ref{a5f}) is equivalent to

\section{Private Completion}

We now target our next goal to  extablish the precise relationship between n-Queens programs B and C. 
We start by noting that these programs share predicate constant $q/2$ while predicate constants  $d1/3$ and $d2/3$ are unique to program C.  
Yet, if we consider the output/extrenal behavior of program $C$ we find atoms constructed with predicate constants $d1/3$, $d2/3$ ``inessential''; it is atoms constructed with predicate constant $q/2$ that encode the solution. \cite{fan23a} formalized the notion of {\em external behavior} and defined the {\em equivalence with respect to a user guide}.
The key to that equivalence is the allowance to treat predicate symbols differently. In particular, in our sample programs the predicate constant $q/2$ is treated as an \emph{output} one, while $d1/3$ and $d2/3$ are treated as \emph{private} predicate constants.  Such distinction allows us to extend the notion of completion to programs with private predicate constants.

For a program $\Pi$ with private predicate constants $\{p_1,\dots,p_k\}$, we first associate predicate variables $P_1,\dots,P_k$ with them, respectively so that their arity and sorts coincide. Then
we define the completion of $\Pi$ with respect to $\{p_1,\dots,p_k\}$ as the formula obtained from the completion of $P$ by replacing the predicate constants $p_1,\dots,p_k$ with the associated predicate variables $P_1,\dots,P_k$, respectively.  The resulting formula is denoted by $\mathit{comp}(\Pi,\{p_1,\dots,p_k\})$.

\section{Alterbative definition of Private Completion}


For a program $P$ with private predicate constants $\{p_1,\dots,p_k\}$, we first associate with them pair-wise distinct predicate variables $P_1,\dots,P_k$, respectively so that their arity and sorts coincide. 
The \emph{private completion} of a normal program~$\Pi$ with private predicate constants $\{p_1,\dots,p_k\}$, denoted by $\mathit{comp}(P,\{p_1,\dots,p_k\})$,
starts by constructing the following formula
\beq
\forall C_1\cdots C_m \big((F_1(C_1)\land\cdots\land F_m(C_m))
\to \exists D_1\cdots D_k (G^p(C_1,\dots,C_m) \land G^o(C_1,\dots,C_m))\big),
\eeq{compP}
where
\begin{itemize}
\item $G^p(C_1,\dots,C_m)$ is the conjunction of
\begin{itemize}
\item the completed definitions of all {\em private} predicate constants occurring
  in~$\nu(\Pi)$
\end{itemize}  
\item $G^o(C_1,\dots,C_m)$ is the conjunction of
\begin{itemize}
\item   the completed definitions of all {\em non-private} predicate constants occurring
  in~$\nu(\Pi)$, and
\item the formulas~$\nu(R)$ for all constraints~$R$ in~$\Pi$
\end{itemize}
\end{itemize}
Private completion  $\mathit{comp}(P,\{p_1,\dots,p_k\})$ is the universal closure of the formula
obtained from~\eqref{compP} by replacing the predicate constants $p_1,\dots,p_k$ with the associated predicate variables $P_1,\dots,P_k$, respectively.  
For a semi-normal program~$\Pi$, $\mathit{comp}(\Pi,\{p_1,\dots,p_k\})$ is defined as
