\paragraph{N-Queens Puzzle: Programs A, B, and C verbatim}
  
We would like to show how reasoning in classical first-order logic can
be used to verify equivalence of two encodings of the $n$-Queens
puzzle \cite[Tables~2 and~3]{geb11b}:
\medskip

\begin{center}Program $A$\end{center}
$$
\ba l
n\,\{ q(1\,..\,n,1\,..\,n) \}\, n\\
\ar q(X,Y_1) \land q(X,Y_2) \land Y_1 < Y_2\\
\ar q(X_1,Y) \land q(X_2,Y) \land X_1 < X_2\\
\ar q(X_1,Y_1) \land q(X_2,Y_2) \land X_1 < X_2 \land |X_1-X_2| = |Y_1-Y_2|
\ea
$$


\medskip
\begin{center}Program $B$\end{center}
$$\ba l
\{ q(1\,..\,n,1\,..\,n) \}\\
\ar X = 1\,..\,n \land \no\ 1\, \{ q(X,Y) \}\, 1\\
\ar Y = 1\,..\,n \land \no\ 1\, \{ q(X,Y) \}\, 1\\
\ar Z = 1\,..\,2\times n-1 \land \no\   \{ q(X,Y) : Z = X-Y+n \}\, 1\\
\ar Z = 1\,..\,2\times n-1 \land \no\   \{ q(X,Y) : Z = X+Y-1 \}\, 1\\
\ea
$$


The lines presented below change Program B 
to Program $C$. In particular Program C is obtained by modifying Program B
as follows 
\begin{itemize}
\item replace the last two rules of Program B with the  content:
\end{itemize}
    %\lstinputlisting[language=Prolog, numbers=left, caption="Part of Program C"]
%{queen4.lp}
\medskip
\begin{center}Part of Program $C$\end{center}
$$\ba l
d1(X,Y,X-Y+n) \ar X = 1..n, Y = 1..n.\\
d2(X,Y,X+Y-1) \ar X = 1..n, Y = 1..n.\\
\ar Z = 1..2\times n-1, not\ \{ q(X,Y) : d1(X,Y,Z) \} 1.\\
\ar Z = 1..2\times n-1, not\ \{ q(X,Y) : d2(X,Y,Z) \} 1.
\ea
$$

\paragraph{Programs A, B, C in the language of Section~\ref{sec:nnf}}
We now present Programs A, B, and C in the language of Section~\ref{sec:nnf}.
In particular,
some rules in these programs implicitly refer to the \co\ aggregate, and
we view choice rules as abbreviations for rules with an atom in
the head.  Written out in full, the Programs A and B become
\begin{align}
& q(X,Y) \ar \no\   \no\   q(X,Y) \land X = 1\,..\,n \land Y = 1\,..\,n	\label{a1}\\
& \ar \no\ n\leq  \co\{ X,Y : q(X,Y) \land X = 1\,..\,n \land Y = 1\,..\,n \}
  \leq n
  \label{a2}\\
& \ar q(X,Y_1) \land q(X,Y_2) \land Y_1 < Y_2\label{a3}\\
& \ar q(X_1,Y) \land q(X_2,Y) \land X_1 < X_2\label{a4}\\
& \ar q(X_1,Y_1) \land q(X_2,Y_2) \land X_1 < X_2 \land |X_1-X_2| = |Y_1-Y_2|
  \label{a5}
\end{align}

\noindent and

\begin{align}
& q(X,Y) \ar \no\   \no\   q(X,Y) \land X = 1\,..\,n \land Y = 1\,..\,n\label{b1}\\
& \ar X = 1\,..\,n \land \no\ 1\leq \co\{ Y : q(X,Y) \} \leq 1\label{b2}\\
& \ar Y = 1\,..\,n \land \no\ 1\leq \co\{ X : q(X,Y) \} \leq 1\label{b3}\\
& \ar Z = 1\,..\,2\times n-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X-Y+n \} \leq  1
  \label{b4}\\
& \ar Z = 1\,..\,2\times n-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X+Y-1 \} \leq  1
  \label{b5}
\end{align}

The four rules of Program C that replace the last two rules of Program B stand for

\begin{align}
&d1(X,Y,X-Y+n) \ar X = 1..n\wedge  Y = 1..n.\label{c4}\\
&d2(X,Y,X+Y-1) \ar X = 1..n\wedge Y = 1..n.\label{c5}\\
&\ar Z = 1..2\times n-1\wedge not\ count \{ X,Y: q(X,Y) , d1(X,Y,Z) \} \leq 1.\label{c6}\\
&\ar Z = 1..2\times n-1\wedge not\ count   \{X,Y:  q(X,Y) , d2(X,Y,Z) \} \leq 1.\label{c7}    
\end{align}

\section{Programs A, B, C as formulas}
Most rules among~\eqref{a1} through~\eqref{c7} are in NNF, except rules~\eqref{b4},~\eqref{b5} and~\eqref{c4},~\eqref{c6}, and ~\eqref{c7} that are semi-normal.


We now transform these rules into formulas using natural translation~$\nu$. 

Rule~\eqref{a1} is transformed into the following formula:
\beq
\forall I J (\neg\neg q(I,J) \land 1\leq I \leq n \land 1 \leq J \leq n \to q(I,J)).
\eeq{a1f}

The representation of rule~(\ref{a2}) includes the function variable~$S_1$, 
 which
is meant to be used in accordance with the set definition $\sd(S_1)$ 
\beq
\forall V(V\in S_1 \lrar \exists IJ(V=(I,J)\land q(I,J) \land 1\leq I\leq n
\land 1\leq J\leq n)).
\eeq{d1}
The formula corresponding to rule~(\ref{a2}) is
\beq
(n\leq \co(S_1)\leq n)\rar\bot.
\eeq{a2f}

Rules~(\ref{a3})--(\ref{a5}) become
\beq
\forall XY_1Y_2\big((q(X,Y_1) \land q(X,Y_2) \land Y_1 < Y_2) \to \bot\big),
\eeq{a3f}
\beq
\forall X_1X_2Y\big((q(X_1,Y) \land q(X_2,Y) \land X_1 < X_2) \to \bot\big)
\eeq{a4f}
and
\beq
\forall I_1I_2J_1J_2
\big((q(I_1,J_1) \land q(I_2,J_2) \land I_1<I_2 \land |I_1-I_2|=|J_1-J_2|) \to \bot\big).
\eeq{a5f}




Rule~\eqref{b1} is identical to rule~\eqref{a1}.
 The representation
of rule~(\ref{b2}) includes the function variable~$S_2$, which
is meant to be used in accordance with the set definition $\sd(S_2)$ 
\beq
\forall V I\Big(V\in S_2(I) \lrar \exists Y\big( V=(Y) \wedge q(I,Y)\big)\Big).
\eeq{d2}
The formula corresponding to rule~(\ref{b2}) is
\beq
\forall I(1\leq I\leq n \land \neg (1\leq \co(S_2(I))\leq 1))\to \bot.
\eeq{b2f}
Translating rule~(\ref{b3}) is similar; it involves the set definition $\sd(S_3)$:
\beq
\forall V J\Big(V\in S_3(J) \lrar \exists X\big( V=(X) \wedge q(X,J)\big)\Big).
\eeq{d3}
and formula
\beq
\forall J(1\leq J\leq n \land \neg (1\leq \co(S_3(J))\leq 1))\to \bot.
\eeq{b3f}

% \end{adjustwidth}

Recall that rules~(\ref{b4}) and~(\ref{b5}) are not in NNF, but they are semi-normal.  For clarity, we present the transformation of these rules  into NNF using the outlined procedure in Section~\ref{sec:nnf}:
\begin{align*}
& \ar Z = 1\,..\,2\times U-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X-Y+U \} \leq  1\wedge U=n
  \\
& \ar Z = 1\,..\,2\times U-1
  \land \no\   \co\{ X,Y : q(X,Y) \land Z = X+Y-1 \} \leq  1 \wedge U=n
\end{align*}


Rules~(\ref{b4}) and~(\ref{b5})  are converted into formulas containing new function variables~$S_4$
and~$S_5$:
\beq
\forall KN\big((1\leq K\leq 2\times N-1 \land\neg\co(S_4(K,N))\leq 1\wedge N=n)\to\bot\big),
\eeq{b4f}
\beq
\forall K\big((1\leq K\leq 2\times N-1 \land\neg\co(S_5(K))\leq 1\wedge N=n)\to\bot\big),
\eeq{b5f}
so that  $\sd(S_4)$ and $\sd(S_5)$ follow: 
\beq
\forall VKN(V\in S_4(K,N) \lrar \exists IJN(V=(I,J) \land q(I,J)
   \land K=I-J+N)),
\eeq{d4}
\beq
\forall VK(V\in S_5(K) \lrar \exists IJ(V=(I,J) \land q(I,J)
   \land K=I+J-1)).
\eeq{d5}


Rule~\eqref{c4} is captured by the  formula:
\beq
\forall I J  N(1\leq I\leq n \land 1\leq J\leq n  
 \wedge N=n\to d1(I,J,I-J+N)).
\eeq{c4f}
Rule~\eqref{c5} is captured by the  formula:
\beq
\forall I J  (1\leq I\leq n \land 1\leq J\leq n \land 
 \to d2(I,J,I+J-1)).
\eeq{c5f}
Rules~(\ref{c6}) and~(\ref{c7})  are converted into formulas containing new function variables~$S_6$
and~$S_7$:
\beq
\forall KN(1\leq K\leq 2\times N-1 \land\neg\co(S_6(K))\leq 1\wedge N=n)\to\bot,
\eeq{c6f}
\beq
\forall KN(1\leq K\leq 2\times N-1 \land\neg\co(S_7(K))\leq 1\wedge N=n)\to\bot,
\eeq{c7f}
so that  $\sd(S_6)$ and $\sd(S_7)$ follow: 
\beq
\forall VK\Big(V\in S_6(K) \lrar \exists IJ\big(V=(I,J) \land q(I,J) \land d1(I,J,K)\big)\Big),
\eeq{d6}
\beq
\forall VK\Big(V\in S_7(K) \lrar \exists IJ\big(V=(I,J) \land q(I,J) \land d2(I,J,K)\big)\Big).
\eeq{d7}

To stress the similarity between some of the formulas stemming from the translation we introduce notation for substitutions. For a formula $F$, by $\sub{F}{t}{t'}$ we denote the formula constructed from $F$ by replacing all occurrences of function symbol (constant or variable) $t$ in $F$ with function symbol (constant or variable) $t'$. 
Using this notation, it is easy to see that  $\sub{\eqref{b4f}}{S_4}{S_6}$ stands for \eqref{c6f}
and  $\sub{\eqref{b4f}}{S_4}{S_7}$ stands for \eqref{c7f}.
%Thus, for example, $\sub{\eqref{b4f}}{S_4}{S_5}$ stands for \eqref{b5f}.
Similarly, for a formula $F$, by $\sub{F}{p}{p'}$ we denote the formula constructed from $F$ by replacing all occurrences of predicate symbol (constant or variable) $p$ in $F$ with predicate symbol (constant or variable) $p'$.

\section{Completions of Programs}
We now proceed toward building completions for Programs B and C.  In this process we note that formulas~\eqref{a1f},~\eqref{c4f}, and~\eqref{c5f} are not completable due to the use of integer variables in the ``head'' atom. We rewrite them as follows (respectively):
\beq
\forall I J X Y (\neg\neg q(I,J) \land 1\leq I \leq n \land 1 \leq J \leq n \wedge X=I\wedge Y=J
 \to q(X,Y)).
\eeq{a1fc}
\beq
\forall I J K X Y Z(1\leq I\leq n \land 1\leq J\leq n \land 
K=I-J+n \land X=I \land Y=J \land Z=K \to d1(X,Y,Z)).
\eeq{c4fc}
\beq
\forall I J K X Y Z(1\leq I\leq n \land 1\leq J\leq n \land 
K=I+J-1 \land X=I \land Y=J \land Z=K \to d2(X,Y,Z)).
\eeq{c5fc}


\paragraph{Completion of Program B}
The completed definition of $q$ is constructed from~\eqref{a1fc} and has the form:
\beq
\forall X Y \Big(q(X,Y)\lrar\exists I J(\neg\neg q(I,J) \land 1\leq I \leq n \land 1 \leq J \leq n \wedge X=I\wedge Y=J)\Big).
\eeq{a1fcomplete}
The remaining formulas of Program B are already ``complete''.
The completion of Program B is the conjunction of~\eqref{a1fcomplete},~\eqref{b2f},~\eqref{b3f},~\eqref{b4f}, and~\eqref{b5f} extended with the respective set definitions~\eqref{d2},~\eqref{d3},~\eqref{d4}, and~\eqref{d5} such that every function variable is existentially quantified:
\beq
\exists S_2~S_3~S_4~S_5\Big(\eqref{a1fcomplete}\wedge 
\eqref{b2f}\wedge\eqref{b3f}\wedge\eqref{b4f}\wedge\eqref{b5f}
\wedge\eqref{d2}\wedge\eqref{d3}\wedge\eqref{d4}\wedge\eqref{d5}\Big).
\eeq{completionB}

\paragraph{Completion of Program C}
The completed definitions for $d1$ and $d2$ are constructed from ~\eqref{c4fc} and~\eqref{c5fc} and have the forms (we rename variables $I,J,K$ to $I_1,J_1,K_1$ to avoid name clashes in the sequel): 
\begin{align}
    &\forall 
X Y Z
\Big(d1(X,Y,Z)
\leftrightarrow \exists I_1 J_1 K_1    
(1\leq I_1\leq n\wedge 1\leq J_1\leq n \wedge K_1=I_1-J_1+n
\wedge X=I_1 \wedge Y=J_1 \wedge Z=K_1 ) 
   \Big).\label{d1fcomplete}\\
&\forall  
X Y Z
\Big(d2(X,Y,Z) \leftrightarrow \exists I_1 J_1 K_1
    (1\leq I_1\leq n\wedge 1\leq J_1\leq n \wedge K_1=I_1+J_1-1 
\wedge X=I_1 \wedge Y=J_1 \wedge Z=K_1 )
   \Big).\label{d2fcomplete}
\end{align}

The completion of Program C is the conjunction of~\eqref{a1fcomplete},~\eqref{b2f},~\eqref{b3f},~\eqref{d1fcomplete},~\eqref{d2fcomplete},~\eqref{c6f}, and~\eqref{c7f}  extended with the respective set definitions~\eqref{d2},~\eqref{d3},~\eqref{d6}, and~\eqref{d7} such that every function variable is existentially quantified.
As our ultimate goal is to analyse the ``equivalence'' of Programs B and C we 
recall that such analysis is performed in the context of a user guide -- a specification on how these programs are meant to be used and their output to be interpreted.
We now note that we assume our user guide for Program C to denote (i) no predicate symbols as input and 
(ii) predicate symbol $q/2$ as the only output one.
Thus, predicate symbols $d1$ and $d2$ are private.
With that when we form an {\em io}-compeltion that ``hides'' predicade symbols 
$d1$ and $d2$ by replacing them with predicate variables $D_1$ and $D_2$ and  existentially quantifying them. The {\em io}-compeltion for Program C is the following formula:

\beq
\exists D_1 D_2 S_2 S_3 S_6 S_7\Big(\eqref{a1fcomplete}\wedge
\eqref{b2f}\wedge\eqref{b3f}\wedge
\sub{\eqref{d1fcomplete}}{d1}{D_1}\wedge 
\sub{\eqref{d2fcomplete}}{d2}{D_2}\wedge 
\eqref{c6f}\wedge\eqref{c7f}
\wedge\eqref{d2}\wedge\eqref{d3}\wedge
\sub{\eqref{d6}}{d1}{D_1}\wedge\sub{\eqref{d7}}{d2}{D_2}\Big).
\eeq{completionC}

\section{Equivalence of io-Completions Programs B and C}
As the user guide for Program B is identical to that of Program C, it is easy to see that io-completion of program B coincides with its completion presnted earlier.
We now show that io-completions of Programs B and C are equivalent, i.e., that the following formula is a tautology
$$
\eqref{completionB}
\lrar
\eqref{completionC}.
$$


To begin with we will start by the equivalent transformation on formulas~\eqref{completionB} and~\eqref{completionC} by moving their existential quantifiers inwards and somewhat rearranging its conjunctive elements.

Formulas \eqref{completionB} and \eqref{completionC} are equivalent to the following formulas respectively:
\beq
\ba l
\eqref{a1fcomplete}\wedge  
\exists S_2\big(\eqref{b2f} \wedge\eqref{d2}\big)
\wedge
\exists S_3 \big(\eqref{b3f} \wedge\eqref{d3}\big)
\wedge\\
\exists S_4\big(\eqref{b4f}\wedge \eqref{d4}\big)
\wedge
\exists S_5\big(\eqref{b5f}\wedge \eqref{d5}\big)
\ea
\eeq{completionBin}
\beq
\ba l
\eqref{a1fcomplete}\wedge  
\exists S_2\big(\eqref{b2f} \wedge\eqref{d2}\big)
\wedge
\exists S_3 \big(\eqref{b3f} \wedge\eqref{d3}\big)
\wedge\\
\exists D_1 S_6\big(\sub{\eqref{d1fcomplete}}{d1}{D_1}\wedge\eqref{c6f} \wedge \sub{\eqref{d6}}{d1}{D_1}\big)
\wedge
\exists D_2 S_5\big(\sub{\eqref{d2fcomplete}}{d2}{D_2}\wedge \eqref{c7f} \wedge\sub{\eqref{d7}}{d2}{D_2}\big)
\ea
\eeq{completionCin}
When io-completions are presented in this form it is easy to see that our goal is derivable from proving that the following two formulas are tautulagies:
\beq
\eqref{a1fcomplete}\rar\Big(
\exists S_4\big(\eqref{b4f}\wedge \eqref{d4}\big)
\lrar
\exists D_1 S_6\big(\sub{\eqref{d1fcomplete}}{d1}{D_1}\wedge \eqref{c6f} \wedge\sub{\eqref{d6}}{d1}{D_1}\big)
\Big)
\eeq{claim1}
and
\beq
\eqref{a1fcomplete}\rar\Big(
\exists S_5\big(\eqref{b5f}\wedge \eqref{d5}\big)
\lrar
\exists D_2 S_5\big(\sub{\eqref{d2fcomplete}}{d2}{D_2}\wedge \eqref{c7f} \wedge \sub{\eqref{d7}}{d2}{D_2}\big)
\Big).
\eeq{claim2}

We start by focusing on the claim that~\eqref{claim1} is a tautology. To this end we focus on the queivalent transformations for its subformula at the righthandside of the equivalence  symbol $\lrar$. This subformula is equivalent to 
$$
\ba l
\exists  S_6\Big(\eqref{c6f} \wedge \\
\forall VK\Big(V\in S_6(K) \lrar \\
\exists IJ\big(V=(I,J) \land q(I,J) \land 
 \exists I_1 J_1 K_1
    (1\leq I_1\leq n\wedge 1\leq J_1\leq n \wedge K_1=I_1-J_1+1 
\wedge I=I_1 \wedge J=J_1 \wedge K=K_1 )
\big)
\Big)
\Big)
\ea
$$
which in turn is equivalent to
$$
\ba l
\exists  S_6\Big(\eqref{c6f} \wedge \\
\forall VK\Big(V\in S_6(K) \lrar \\
\exists IJ\big(V=(I,J) \land q(I,J) \land 
    1\leq I\leq n\wedge 1\leq J\leq n \wedge K=I-J+n 
\big)
\Big)
\Big)
\ea
$$
which under assumption~\eqref{a1fcomplete} is equivalent to
$$
\ba l
\exists  S_6\Big(\eqref{c6f} \wedge \\
\forall VK\Big(V\in S_6(K) \lrar \\
\exists IJ\big(V=(I,J) \land q(I,J) \land 
     \wedge K=I-J+n 
\big)
\Big)
\Big).
\ea
$$
It is easy to see that if we substitute $S_6$ with $S_4$ in the last formula we obtain a formula 
that is at the right hand side of the equivalence symbol $\lrar$ in~\eqref{claim1}.
Thus, we have shown that~\eqref{claim1} is a tautology. The proof for the fact that~\eqref{claim2} is a tautology is similar.

\section{Cryptarithmetic Problem Statement}
A common sample problem to illustrate the key concepts of constrain satisfaction paradigm is the cryptarithmetic problem. The problem is to find a mapping from letters to digits such that a given arithmetic equation holds true. For example, consider the following equation:
\begin{equation}
    \begin{array}{lr}
 &TWO\\
 +&TWO\\
 \hline
 &FOUR
\end{array}
\end{equation}
where we want to assign each letter a number from $0$ to $9$ (except we do not want $T$ or $F$ to be $0$ as customary in arithmetic to ``avoid'' leading zeros) so that they add as in arithmetic.
